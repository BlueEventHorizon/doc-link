# DES-005 対象確定・ID 保証・ToC 構築設計

**状態**: Draft 0.1・未決の確定条件あり\
**更新日**: 2026-09-29\
**根拠**: [管理対象と ID](../requirement/REQ-002-document-id.md)、[ToC 管理](../requirement/REQ-003-toc.md)

## 1. 入出力と実行境界

入力は管理キー、当該キーの完全な管理対象指定、対象 Markdown、当該キーの最後の確定版、処理済み比較基準である。出力は、新しい確定版または失敗診断、未処理変更、参照検査結果である。処理の段階は [DES-004 の B-01〜B-09](DES-004-state-machines.md) に従い、途中候補を現在版として公開しない。初回は既存版がなくても、ID 保証の後に候補を作り確定する。

## 2. 対象確定と ID 保証

1. `--key` と完全な desired state、または予約キー `all` の単体モードを検証する。Forge の設定ファイルは読まず、呼び出し元が解決した指定を使う。
2. ディレクトリ・パターンを具体的な Markdown 一覧に展開し、除外を適用する。指定外の実体は対象へ加えない。正規化した指定は次回の検索で再展開できる形に保つ。
3. 全対象の frontmatter を読み、認識できる `doc_link_id` がない文書だけに ID 管理処理が新しい値を発行・保存する。利用者や生成 AI に採番させない。
4. 保存後に全対象を再確認し、ID 欠落または重複が一件でもあれば後続の差分判定へ進まない。複製文書のどちらが原本かは自動で決めない。

ID の保存だけが管理対象 Markdown への書き込みである。途中で失敗した場合に既に保存された ID は「発行済み」として報告し、次回に内容から再計算しない。重複検出の保証範囲は U-016／旧 R-007、発行仕様は U-001、部分書き込みのロールバックは未決である。

## 3. 変更集合の確定

ID 確定済み一覧を現在のキーの ToC と照合し、少なくとも「新規」「対象離脱」「同じ ID のパス変更」「本文比較値の変更」「参照記述・物理パスの変更」を独立に記録する。一件が複数種別に該当してよい。対象離脱は今回の対象一覧にないことだけで判定し、範囲外を探索して削除か移動かを決めない。

ToC の反映済みハッシュと現物を比較して**索引更新対象**を決め、別の処理済み比較基準と現物を比較して**未報告の変更**を決める。この段階では AI 要約、参照先の実走査、ToC 書き込みを行わない。現在ハッシュが既に ToC に反映済みでも比較基準が旧値なら、要約を再生成せず未報告の変更を残す。

## 4. 必要情報の取得と候補確定

変更種別から更新計画を作り、変更のない文書の AI 生成情報は再利用する。パスだけの変更は現在パスを更新し、内容が同じなら要約を作り直さない。「指定キーの ToC では新規」と「文書 ID 自体が新規」は区別する。文書 ID と論理内容の版に対応する検証済み文書情報が既にある場合、キーへの追加だけを理由に AI へ再生成させない。再利用できる情報がない新規文書、または意味内容が変わった文書に必要な情報だけ AI に生成させ、script が必須値と長さを検査する。指定されていないキーの ToC を更新せず、そのキーの ToC を構築結果の正しさの根拠にも使わない。参照記述は現物から抽出し、参照先の実走査結果と逆参照を候補に組み立てる。キーから独立した文書情報の物理配置と異なる時点の見せ方は旧 R-001 の判断待ちである。

候補は少なくとも ID の一意性、対象集合との対応、参照と逆参照の対応、必須フィールド、比較に用いた現物と候補の整合を検査する。候補作成中に現物が変わった場合、古い観測と新しい観測を一つの「現時点の版」として混在させず、当該候補を再評価または拒否する。検査済み候補だけを一括して公開し、失敗時は旧確定版と旧比較基準を保持する。物理的な原子化方式と同一 ID の複数キー間の共有版境界は旧 R-001／R-004 として未決である。

参照先の指定ディレクトリ内不在とパス不一致は、候補に記録する検査結果であって確定失敗ではない。走査不能時の確定可否は U-020 が未決であり、決定前に暗黙の成功としてはならない。

## 5. 完了と再実行

ToC 確定だけでは処理済み比較基準を進めない。変更と把握済み参照元の報告が完了した対象だけを後続操作で進める。失敗時は段階、対象 ID・パス、原因、公開版の有無、既発行 ID、未報告の変更を返す。再実行時は確定版・比較基準・現物から再判定し、旧版に取り込まれた要約を不必要に繰り返さない。
