# DES-009 要件対応と設計検証

**状態**: Draft 0.1・未決事項の試験値は未確定\
**更新日**: 2026-10-15\
**根拠**: [要件書群](../requirement/REQ-001-overview.md)、[状態モデル](DES-004-state-machines.md)

## 1. テストの規範

状態を持つ処理は [DES-004 の遷移表](DES-004-state-machines.md) を唯一の許可遷移一覧とする。P-01〜P-03、B-01〜B-09 の各行について、元状態・イベント・ガード成立で指定した次状態と効果になることを試す。同じ元状態でガード不成立、表にないイベント、別状態からのイベントを与えたときは拒否し、公開版と比較基準が変わらないことを試す。Mermaid 図は表と同じ遷移を可視化するだけであり、図にない暗黙の遷移を認めない。

参照先の走査不能は候補確定ガードを不成立にしない（決定: U-020）。走査不能・指定ディレクトリ自体の不在・ディレクトリ内不在がそれぞれ「検査不能」「不在」「不在」として記録され、いずれでも確定することを試す。途中中断、再実行、旧確定版保持、部分的に保存済みの ID、複数キーの隔離も状態テストに含める。変更と参照元の報告に失敗した場合は旧比較基準を維持し、次回に未報告の変更を再検出することを試す。

文書単位のロック（[DES-005 §5](DES-005-indexing.md)）は、二つの構築を同時に動かして試す。ロック待ちの後に再比較して生成を省くこと、強制解除でロックを失った構築の書き込みが拒否されること、強制解除がユーザーの確認なしに行われないこと、一つの構築が二つ以上のロックを保持しないこと、ID 未付与の文書がパスでロックされ二重に ID が発行されないこと、検索がロックを待たないことを確認する。

状態遷移でない決定論的処理は別に単体テストを持つ。対象指定の展開、Markdown 解析、ID 認識・発行・重複、パス解決、ディレクトリ走査結果の分類、比較値、AI 出力検証、ToC 候補整合性を対象にする。U-001／U-006／U-007／U-013／U-014 が決まるまで、それらの値に依存する期待値を勝手に固定しない。

## 3. 横断シナリオ

1. 初回：対象指定 → 全文書 ID 保証 → 変更集合 → 必要情報 → 参照実走査 → ToC 確定 → 検索可能。
2. 移動：同じ ID・同じ内容でパスだけ変更し、要約を再生成せず ToC の現在パスを更新する。参照元の古いパスは自動修正しない。
3. 内容変更：ToC 確定後も変更影響候補の報告が未完了なら比較基準は旧値。次回に要約を再生成せず報告を続行する。
4. 失敗：AI 生成・参照走査・候補確定・通知の各失敗位置で旧公開版、旧比較基準、発行済み ID の扱いを区別する。それまでに確定した文書情報行は戻さず、ToC が旧版のキーからも最新の文書情報が見える（決定: 旧 R-004）。
5. 複数キー：同一 ID が A と B に所属し、A の更新・離脱が B の ToC を書き換えない。同じ ID・論理内容版の検証済み情報を再利用できる場合、B への追加だけで AI 要約を再生成しない。B は A と同じ文書情報行を参照するため表示は一致し、報告済み比較基準は (対象 ID, 参照元 ID) の組で判定する（決定: 旧 R-001／R-002）。
6. 範囲外参照：管理対象外でも指定ディレクトリを実走査し、結果に範囲・時点を付ける。対象範囲外への移動先は推測しない。検索時も同様に再走査し、検索結果の参照鮮度を更新する（決定: 旧 R-003）。
7. 同時実行：二つのセッションが同じ文書を含む別キーを構築し、文書情報行の更新と ID 発行が文書単位のロックで直列化され、要約が一度だけ生成される（決定: 旧 R-004）。

## 4. 承認前に決める境界

| 論点                   | 決定しないと確定できない設計・テスト       |
| ---------------------- | ------------------------------------------ |
| U-001／U-016／U-017    | ID 発行・一意性・複製時の処理              |
| U-005／U-006／U-008    | 正式な依存・セクション・間接影響の範囲     |
| U-007                  | 比較値の正準化と意味変更のテストベクトル   |
| U-013／U-014           | フィールド別 `L` と文字数カウント          |
| 旧 R-005／R-006／R-007 | 範囲外移動、逆引きの網羅範囲、重複検出範囲 |

これらは要件書と設計書の両方で解決してから実装の期待値にする。現時点の設計書は実装着手用の確定仕様ではなく、議論可能な構成と契約の初稿である。
