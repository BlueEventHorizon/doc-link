# ToC の構築 DLID-b2b2b2b2b2b2

ToC は、対象の文書から作る。文書の本文が変わったときだけ、文書情報を作り直す。

## 作り直しの条件 DLID-b3b3b3b3b3b3

本文のハッシュが、反映済みのハッシュと違うときに、文書情報を作り直す。移動しただけの文書は、パスだけを新しくする。

## 対象の指定 DLID-b4b4b4b4b4b4

対象は、ディレクトリまたはファイルで指定する。指定は、ToC を識別するキーごとに保存する。

## 参照の検査 DLID-b5b5b5b5b5b5

文書が持つ参照は、参照先のディレクトリを走査して検査する。壊れた参照は、結果として報告する。

## 構築の失敗 DLID-b6b6b6b6b6b6

構築が失敗したときは、新しい ToC を公開せず、旧い ToC を残す。失敗の原因は、文書ごとに報告する。
